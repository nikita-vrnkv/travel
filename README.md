# За горизонт

Готовый адаптивный учебный сайт о путешествиях на русском языке. HTML5, CSS3 и Vanilla JavaScript, без сборки, фреймворков и backend. Две отдельные страницы; бронирований и отправки данных нет.

## Структура

```text
travel/
├── public/
│   ├── index.html
│   ├── about.html
│   ├── css/style.css
│   ├── js/script.js
│   ├── js/theme.js
│   └── images/
│       ├── dolomites.jpg
│       ├── bali.jpg
│       ├── paris.jpg
│       ├── iceland.jpg
│       ├── coast.jpg
│       ├── kyoto.jpg
│       └── favicon.svg
├── qa/ — снимки и проверки
├── .gitignore
└── README.md
```

`theme.js` применяет тему до загрузки стилей. `script.js` управляет меню, темой, фильтрами и прокруткой. Все фотографии локальные; внешние шрифты и библиотеки не требуются. Фото `dolomites.jpg` используется как общий горный пейзаж, без утверждения точного места съёмки.

## Быстрый локальный запуск

Откройте PowerShell в каталоге проекта:

```powershell
cd C:\Users\vonik\Desktop\travel
python -m http.server 8080 --bind 127.0.0.1 --directory public
```

Откройте http://localhost:8080. Остановить сервер: Ctrl+C. Python нужен только для локального HTTP-сервера. Для проверки сохранения темы используйте HTTP, а не открытие файла через `file://`.

## Подготовка к миграции на Vercel

Проект готов к следующему этапу — публикации на Vercel. В рамках текущего этапа Vercel не настраивался, деплой не выполнялся.

- Статический сайт без backend, базы данных, зависимостей и процесса сборки.
- Вся публичная часть находится в `public/`; главная — `index.html`, вторая страница — `about.html`.
- Стили, JavaScript и фотографии находятся внутри `public/` и используют относительные пути.
- Страницы самостоятельные: перенаправление всех адресов на `index.html` не требуется.
- Переменные окружения, Firebase SDK и ключи для работы сайта не нужны.
- Файлы `firebase.json`, `.firebaserc` и кэш `.firebase/` удалены. Firebase CLI в системе не удалялся.

## Проверка перед демонстрацией

- Перейдите по ссылкам в header, footer и кнопкам обеих страниц.
- Выберите «Горы», «Море», «Города»: каждый фильтр показывает две карточки; «Все направления» возвращает шесть.
- Раскройте «Идея для путешествия» в карточке.
- Включите тёмную тему, обновите страницу и перейдите на вторую: выбор сохраняется в localStorage (`horizon-theme`). При запрете хранилища переключение работает в текущей странице.
- На экране до 640 px откройте бургер-меню. Закройте его повторным нажатием, Escape, выбором ссылки или нажатием вне header.
- Прокрутите страницу ниже 450 px: появится кнопка наверх.
- Проверьте ширины 320, 390, 768 и 1440 px, обе темы и навигацию клавишей Tab.
- В инструментах разработчика проверьте отсутствие ошибок Console и ошибок загрузки в Network.

Предусмотрены семантическая разметка, alt-тексты, видимый фокус, ссылка пропуска навигации, aria-pressed/aria-expanded, уведомление о результатах фильтра, prefers-reduced-motion. Без JavaScript видны все карточки и навигация, раскрывающиеся советы работают средствами HTML.

Эта запись описывает проверки при первоначальной разработке; актуальное состояние прежнего Hosting указано выше.
